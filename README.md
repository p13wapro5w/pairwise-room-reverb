# pairwise-room-reverb

角色从走廊走进大厅，混响尾巴突然断掉，混响区域切换用硬边界，跨过门槛瞬间 IR 直接替换；early 和 late 反射共用一个延迟，大厅的早期反射听起来像走廊；IR 按 44.1k 录制却塞进 48k 引擎，尾巴整体短了百分之八；声源快速移动时多普勒只改了音高没改延迟，脚步和混响对不上；墙体遮挡只判断视线，绕过门洞的反射路径被整条掐掉；portal 连接的两个房间各自算混响，穿过门时能量翻倍；混响总线在 5.1 下混时中置重复计入，对白变响；性能档直接关掉 late 反射，房间瞬间变干；预延迟按固定毫秒，小房间的早期反射和直达声重叠；多条 IR 交叉淡化按线性振幅，过渡中点能量掉一半。media/room_reverb.py 是核心，tests/test_room_reverb.py 15个红。要修的是：区域切换按声源位置插值；early 与 late 分开建模；IR 重采样到引擎采样率；移动声源更新延迟；遮挡按路径而非视线；portal 能量守恒；下混按声道矩阵；降档保留短混响；预延迟按房间尺寸；交叉淡化按能量归一。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
